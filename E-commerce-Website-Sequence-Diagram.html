E-commerce Website (Stylish) – Dynamic Product Fetching
Prepared by Tle  |  April 28, 2026  |  Version 1.0
About this document. This sequence diagram illustrates the data flow when the website dynamically loads product data using a fetch() GET request instead of hard-coded HTML. It covers the happy path (successful load), loading state, and error handling.

SEQ-01Get Product Data & Display (Happy Path)

When the page loads, JavaScript sends a GET request to fetch product JSON data from the server, then renders the products dynamically into the DOM.
sequenceDiagram actor User as User (Browser) participant JS as JavaScript (Client) participant Server as Web Server participant DOM as DOM (HTML Page) User->>JS: Page loaded (DOMContentLoaded) JS->>DOM: Show loading spinner JS->>JS: requestProducts() JS->>Server: fetch("./data/json/products.json") Note over JS,Server: GET Request sent over HTTP Server-->>JS: return JSON (200 OK) Note over Server,JS: Response contains array of 20 products JS->>JS: Parse JSON response JS->>DOM: renderProducts(products) Note over JS,DOM: Loop through products array,
create HTML card for each product,
inject into #product-container DOM-->>User: Display product grid

SEQ-02Loading State (Data in Transit)

While the data is traveling from the server to the browser, the user sees a loading indicator instead of an empty page.
sequenceDiagram actor User as User (Browser) participant JS as JavaScript (Client) participant Server as Web Server participant DOM as DOM (HTML Page) User->>JS: Page loaded JS->>DOM: Show "Loading products..." spinner JS->>Server: fetch("./data/json/products.json") Note over JS,Server: ⏳ Network latency...
Data is traveling DOM-->>User: User sees loading spinner Server-->>JS: return JSON JS->>DOM: Remove spinner JS->>DOM: renderProducts(products) DOM-->>User: Products appear on screen

SEQ-03Error Handling (Cannot Load Data)

If the JSON file cannot be found or the server returns an error, the catch block handles it gracefully and informs the user.
sequenceDiagram actor User as User (Browser) participant JS as JavaScript (Client) participant Server as Web Server participant DOM as DOM (HTML Page) User->>JS: Page loaded JS->>DOM: Show loading spinner JS->>JS: requestProducts() JS->>Server: fetch("./data/json/products.json") Server-->>JS: 404 Not Found / Network Error Note over Server,JS: ❌ File not found or server down JS->>JS: catch(error) JS->>DOM: Remove spinner JS->>DOM: Show error message Note over JS,DOM: "Failed to load products.
Please try again later." JS->>JS: console.error(error) DOM-->>User: User sees error message
Actors & Objects Reference
Actor / ObjectRoleDescription
User (Browser) Actor The end user who visits the website and triggers the page load event.
JavaScript (Client) Object The client-side script (products.js) that contains requestProducts(), fetch(), and renderProducts() functions.
Web Server Object The HTTP server (e.g., Live Server) that hosts and serves the products.json file.
DOM (HTML Page) Object The Document Object Model — the live HTML structure where products are rendered into #product-container.
Arrow Labels Reference
Arrow LabelTypeDescription
requestProducts() Function call Entry point function that initiates the data fetching process.
fetch() HTTP GET Asynchronous GET request to retrieve the JSON data file from the server.
return JSON HTTP Response Server responds with the JSON array of product objects.
renderProducts() Function call Processes the JSON data and dynamically creates HTML elements in the DOM.
